# 风险颜色、预警线与运行时间

原生面板编辑器可以设置预警值和严重值，要求两个有限数值且严重值大于预警值。低于预警为绿色，到达预警为黄色，到达严重为红色；留空清除。未修改阈值时保存标题等其它属性会保留原始色阶、命名色及查询配置。配置通过现有面板 PATCH 和仪表盘 `If-Match` 版本保护保存。

时间序列按每个历史数值所在区间着色，不能因为最新值恢复就把过去的严重峰值重画成绿色。同轴各序列阈值一致时才显示共用风险背景和虚线；阈值文字独立展示。百分比线性轴包含通常的 0–100% 或 0–1 范围，同时保留越界样本；对数轴保持原有范围。百分比类型的阈值只有明确有限的 min/max 时才能换算。SDK 命名色先解析为实际 Canvas 颜色，非法色安全回退，不中断整张图。

风险颜色仅表示数值区间，不会创建或触发通知。告警还要独立配置持续时间、恢复确认、无数据/查询错误策略和通知冷却。短尖峰可以显示为红色但不发送告警。当前正式资源规则的具体阈值和持续时间属于私有部署策略，不硬编码成所有业务的默认值。

运行时间采用 `visualization: "stat"`、`unit: "uptime"`，显示天/时/分/秒，无数据为 `—`。新建系统仪表盘默认如此；已有仪表盘不被数据库初始化覆盖，应通过受版本保护的面板编辑更新，以保留用户自定义内容。

验证包括历史阈值颜色坐标、边界与非法色单测，以及实际浏览器 Canvas 像素、中文引导、阈值保存/查询保留、命名色/非法色和数字运行时间测试。外部通知另按告警与投递契约验收。
